# Thanjavur Tourist Social Network Analysis

## Concepts Covered
- Ties (Edges)
- Density
- Path Length
- Distance
- Betweenness Centrality
- Degree Centrality
- Closeness Centrality
- Clique Detection

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   cd src
   python main.py

## Output
- Graph Image: output/graph.png
- Metrics: output/metrics.txt
